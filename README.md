A one-line joke about office life, written for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty — the sort of line you send a colleague after a meeting that should have been an email. The program prints the joke, a single line of 136 characters (under the 200-character limit), and validates its own length before printing it.
